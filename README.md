# Бот для сканирования документов в Telegram

Бот принимает фотографию документа, определяет границы листа, выравнивает перспективу, удаляет тени и возвращает скан в виде PDF.

**Возможности**

- автоматическое определение границ листа и выравнивание перспективы;
- фильтры: Ч/Б (копия с белым фоном), Серый, Цвет, Оригинал;
- поворот, отмена обрезки, удаление страницы;
- многостраничный PDF формата A4 из нескольких фотографий или альбома;
- «Удостоверение на A4»: обе стороны удостоверения на одном листе в натуральную величину;
- распознавание текста (русский, казахский, английский): текст и PDF с возможностью поиска;
- интерфейс на русском и английском языках.

Изображения обрабатываются на компьютере, где запущен бот, и третьим лицам не передаются. Документы хранятся только в оперативной памяти и удаляются через 24 часа или при перезапуске бота. На диске сохраняется только выбранный язык интерфейса (файл `prefs.json`).

## Установка

### 1. Создание бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Задайте имя бота и username, оканчивающийся на `bot`.
3. Сохраните полученный **токен** (вида `1234567890:AAH...`). Токен даёт полный доступ к боту, не передавайте его третьим лицам.

### 2. Установка Python

Если Python не установлен, скачайте его с [python.org/downloads](https://www.python.org/downloads/). В установщике отметьте пункт **«Add python.exe to PATH»**.

Вариант для PowerShell: `winget install -e --id Python.Python.3.13`

### 3. Размещение файлов

Скачайте проект (на GitHub: **Code → Download ZIP**) и распакуйте архив в папку с путём без кириллицы, например `C:\telegram-doc-scanner`.

### 4. Распознавание текста (рекомендуется)

Запустите **`install_ocr.bat`**. Скрипт установит Tesseract; подтвердите запрос Windows на установку. Языковые модели бот загрузит при первом запуске.

Без этого шага бот работает, но кнопка «Распознать текст» будет недоступна.

### 5. Запуск

Запустите **`start.bat`**.

- При первом запуске скрипт установит библиотеки (1–3 минуты) и запросит токен. Вставьте его (правая кнопка мыши или Ctrl+V) и нажмите Enter. Токен сохраняется в файле `.env`.
- После сообщения `Бот @имя_бота запущен` откройте бота в Telegram и нажмите «Запустить».

Бот работает, пока открыто окно. При сбое он перезапускается автоматически.

### 6. Автозапуск

Запустите **`autostart.bat`**: бот будет запускаться в свёрнутом окне при входе в Windows. Повторный запуск скрипта отключает автозапуск.

Отключите спящий режим: Параметры → Система → Питание → «Переводить в спящий режим» → «Никогда». В спящем режиме бот не отвечает.

## Рекомендации по съёмке

- Документ на тёмной однотонной поверхности, все четыре угла в кадре.
- Равномерное освещение, без вспышки и бликов.
- Наилучшее качество: отправка фотографии файлом (в Telegram: «Прикрепить» → «Файл»).
- Если граница листа определена неверно, нажмите «Без обрезки».

## Язык интерфейса

Язык выбирается автоматически по настройкам Telegram пользователя: русский для русского, казахского и других языков СНГ, английский для остальных. При первом запуске бот предлагает выбрать язык. Изменить выбор можно командой `/language`; он сохраняется и после перезапуска бота.

## Удостоверение на A4

Нажмите «Удостоверение на A4» и отправьте лицевую, затем оборотную сторону. Обе стороны размещаются на листе A4 в натуральную величину (85,6 × 54 мм). Рекомендуемые фильтры: Серый или Ч/Б. Для поворота стороны используйте кнопки «Лицевая ↻» и «Оборотная ↻».

Лист добавляется в текущий документ и может входить в один PDF с другими страницами.

## Настройки (файл `.env`)

Файл создаётся при первом запуске. После изменения настроек перезапустите бота.

| Параметр | Назначение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ALLOWED_USERS` | Telegram ID или @username пользователей через запятую. Пустое значение: доступ открыт всем. ID можно узнать командой `/myid` |
| `OCR_LANG` | языки распознавания через `+`, по умолчанию `rus+kaz+eng` |
| `TESSERACT_CMD` | путь к `tesseract.exe`, если он не найден автоматически |
| `DEFAULT_FILTER` | фильтр для новых страниц: `bw`, `gray`, `color`, `orig` |

Пример ограничения доступа:

```
ALLOWED_USERS=123456789, @kollega
```

## Неполадки

| Проблема | Решение |
|---|---|
| «Python is not installed» | Установите Python (шаг 2) с пунктом «Add python.exe to PATH» и повторите запуск. |
| Бот не отвечает | Проверьте, что окно бота открыто, компьютер не в спящем режиме и есть интернет. Журнал: `bot.log`. |
| «Бот уже запущен в другом окне» | Одновременно допускается один экземпляр бота. Закройте лишнее окно. |
| Нет кнопки «Распознать текст» | Запустите `install_ocr.bat` и перезапустите бота. Причина указана в `bot.log` (строка `OCR выключен`). |
| «Границы листа не определены» | Переснимите документ на контрастной тёмной поверхности, все четыре угла в кадре. |
| «Файл превышает 20 МБ» | Ограничение Telegram. Отправьте изображение как фото или уменьшите его. |
| Смена токена | Измените строку `BOT_TOKEN=` в файле `.env`. |

## Состав

| Файл | Назначение |
|---|---|
| `start.bat` | запуск бота |
| `install_ocr.bat` | установка Tesseract |
| `autostart.bat` | включение и отключение автозапуска |
| `run.py` | подготовка окружения, перезапуск при сбоях |
| `bot.py` | логика Telegram-бота |
| `scanner.py` | определение границ, выравнивание, фильтры |
| `pdfmaker.py` | формирование PDF и листа «Удостоверение на A4» |
| `texts.py` | тексты интерфейса на русском и английском |
| `ocr.py` | распознавание текста |
| `docs.py` | хранение документов в памяти |
| `config.py` | чтение настроек |
| `requirements.txt` | зависимости Python |

Запуск вручную: `python -m venv .venv`, затем `.venv\Scripts\pip install -r requirements.txt` и `.venv\Scripts\python bot.py`.
